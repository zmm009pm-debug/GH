# GH💻 CAI วิทยาการคำนวณ ม.1 (ว21103)
โรงเรียนนาแกพิทยาคม

แอปพลิเคชันบทเรียนคอมพิวเตอร์ช่วยสอน (Computer-Assisted Instruction: CAI) สำหรับรายวิชาวิทยาการคำนวณ ระดับชั้นมัธยมศึกษาปีที่ 1 ออกแบบมาเพื่อเสริมสร้างทักษะการคิดเชิงคำนวณ (Computational Thinking) โดยเฉพาะ แนวคิดเชิงนามธรรม (Abstraction) และ การออกแบบอัลกอริทึม (Algorithm Design)

📖 ข้อมูลทั่วไป (Project Overview)
รายวิชา: วิทยาการคำนวณ (ว21103)
ระดับชั้น: มัธยมศึกษาปีที่ 1 (รองรับนักเรียน 30 คน)
มาตรฐานการเรียนรู้: สาระที่ 4 เทคโนโลยี มาตรฐาน ว 4.2
ตัวชี้วัด: ว 4.2 ม.1/1 ออกแบบอัลกอริทึมที่ใช้แนวคิดเชิงนามธรรมเพื่อแก้ปัญหาหรืออธิบายการทำงานที่พบในชีวิตจริง
🏗️ สมมติฐานการออกแบบและข้อจำกัดของระบบ (Assumptions & Limitations)
เนื่องจากระบบนี้เป็นแอปพลิเคชันที่ทำงานบนฝั่ง Client (Front-end) เพียงไฟล์เดียวเพื่อให้สามารถ Preview ได้ทันที จึงได้กำหนดสมมติฐานการทำงานดังนี้:

Mock Backend (Supabase): ระบบฐานข้อมูลและระบบยืนยันตัวตน (Authentication) ถูกจำลองขึ้นมาแบบ In-memory (ตัวแปร MOCK_STUDENTS และ supabaseService) แทนที่การต่อเชื่อม Supabase จริง
นักเรียน 30 คน: ระบบได้สุ่มสร้างรายชื่อและรูปโปรไฟล์นักเรียนจำนวน 30 คนให้โดยอัตโนมัติ เพื่อให้ครูสามารถเห็นภาพรวมของระบบ Dashboard ได้ทันที
Storage: ระบบอัปโหลดไฟล์ใน Teacher Dashboard เป็นเพียง UI สำหรับสาธิต ไม่ได้มีการบันทึกไฟล์ลงเซิร์ฟเวอร์จริง
เนื้อหา (No AR/VR): ตัดเทคโนโลยี AR, VR หรือ WebAR ออกตามข้อกำหนด เน้นที่ Interactive Web Elements และ Gamification (การลากวาง, การเลือกคำตอบ) แทน
🚀 ฟีเจอร์หลัก (Key Features)
1. 🎓 ฝั่งนักเรียน (Student Canvas)
หน้าเข้าสู่ระบบ: เลือกชื่อนักเรียนจากรายชื่อ 30 คน (Demo)
ระบบสะสมความก้าวหน้า: แสดงคะแนน (Score) และแถบความก้าวหน้า (Progress Bar)
บทเรียนที่ 1: แนวคิดเชิงนามธรรม: ภารกิจจำลองสถานการณ์เลือกซื้อโทรศัพท์มือถือ ให้นักเรียนคัดแยกข้อมูลที่ "สำคัญ" และ "ไม่สำคัญ" (Abstraction)
บทเรียนที่ 2: การออกแบบอัลกอริทึม: ภารกิจต้มบะหมี่กึ่งสำเร็จรูป ให้นักเรียนนำข้อมูลมาจัดเรียงลำดับขั้นตอน (Algorithm) ให้ถูกต้อง
2. 👨‍🏫 ฝั่งครูผู้สอน (Teacher Dashboard - Supabase Admin)
ตารางสรุปผลการเรียน (Progress Tracking): ดูความก้าวหน้า, คะแนนรวม, และเวลาเข้าใช้งานล่าสุดของนักเรียนทั้ง 30 คน แบบ Real-time
ระบบจัดการสื่อ (Media Storage): จำลองการทำงานของการอัปโหลดไฟล์สื่อการสอนและใบงานขึ้น Supabase Storage
📊 เกณฑ์การประเมินผล (Rubric Score)
เกณฑ์การประเมินผลสำหรับตัวชี้วัด ว 4.2 ม.1/1 (คะแนนเต็ม 4 ระดับ) นำมาประยุกต์ใช้กับผลลัพธ์ในระบบ Dashboard

สมรรถนะที่ประเมิน	ระดับ 4 (ดีมาก)	ระดับ 3 (ดี)	ระดับ 2 (พอใช้)	ระดับ 1 (ปรับปรุง)
1. การใช้แนวคิดเชิงนามธรรม (Abstraction)	แยกแยะข้อมูลที่สำคัญและไม่สำคัญออกจากสถานการณ์ได้อย่างถูกต้องสมบูรณ์ 100%	แยกแยะข้อมูลสำคัญได้ถูกต้องส่วนใหญ่ มีข้อผิดพลาดเล็กน้อย (80%)	แยกแยะข้อมูลสำคัญและไม่สำคัญได้บางส่วน ต้องอาศัยการชี้แนะ	ไม่สามารถคัดแยกข้อมูลที่จำเป็นต่อการแก้ปัญหาได้เลย
2. การออกแบบอัลกอริทึม (Algorithm)	เรียงลำดับขั้นตอนการแก้ปัญหาได้อย่างถูกต้อง ชัดเจน และมีประสิทธิภาพ	เรียงลำดับขั้นตอนได้ถูกต้อง แต่กะทัดรัดหรืออาจมีสลับขั้นตอนที่ยอมรับได้	ลำดับขั้นตอนการแก้ปัญหายังมีความสับสน ข้ามขั้นตอนที่สำคัญ	ไม่สามารถเรียงลำดับขั้นตอนการแก้ปัญหาได้ หรือทำแล้วไม่เกิดผลลัพธ์
หมายเหตุ: ในระบบ CAI หากนักเรียนทำภารกิจผ่าน จะถือว่าอยู่ในเกณฑ์ "ดีมาก" ทันที ระบบถูกออกแบบให้ทดลองทำซ้ำได้จนกว่าจะถูกต้อง (Mastery Learning)

💻 Stack เทคโนโลยี (Tech Stack)

Data Layer: In-memory Javascript Arrays & Promises (จำลอง Supabase)
